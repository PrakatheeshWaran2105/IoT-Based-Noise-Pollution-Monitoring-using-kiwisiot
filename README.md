# IoT-Based-Noise-Pollution-Monitoring-using-kiwisiot
IoT-Based Noise Pollution Monitoring using NodeMCU ESP8266 and KY-038 sound sensor to detect surrounding noise levels and monitor real-time sound sensor readings through the KiwisIoT platform.
IoT-Based Noise Pollution Monitoring Using ESP8266 and KiwisIoT

About the Project

The IoT-Based Noise Pollution Monitoring System uses a NodeMCU ESP8266 and a KY-038 sound sensor to detect noise levels in the surrounding environment. The sound sensor captures changes in sound intensity and sends the readings to the ESP8266.

The ESP8266 connects to Wi-Fi and transmits the sensor readings to the KiwisIoT platform, where users can monitor noise levels in real time through an IoT dashboard. This project demonstrates how IoT technology can help observe environmental noise in places such as homes, schools, offices, and public areas.
